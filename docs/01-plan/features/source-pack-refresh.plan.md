## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 공식 자료팩이 산식·표가 이미지인 조문을 통째로 보류해, 실제로 있는 조문 7개가 검색 코퍼스에 없다. 그중 고용보험법 시행령 제104조의2(육아기 단축급여 산식)·제104조의15(노무제공자 소득감소 요건)는 계산기가 인용하는 근거다. 10-09 스냅숏 이후 신설·개정된 조문(임금채권보장법 4·민사집행규칙 15·국민연금법 제126조)도 반영되지 않았다. |
| **Solution** | 보류 규칙을 고쳐 이미지 옆에 함께 오는 표 텍스트(법제처 `조문내용`의 상자 표)를 본문으로 쓰고, 법제처 현행판(eflaw)에서 해당 법령만 다시 받아 **추가 배치**로 적재한다. 기존 배치는 덮어쓰지 않고, 바뀐 조문만 새 배치로 대체한 뒤 구 ID를 원장으로 정리한다. 커밋 원장·BM25 재빌드를 함께 한다. |
| **Function UX Effect** | 단축급여·노무제공자 실업급여·임금채권보장 신설 제도 질문에 시행령·법 원문이 근거로 실린다. 계산기 근거 문구(`legal_anchors`)와 검색 코퍼스가 같은 판본을 가리킨다. |
| **Core Value** | 공식 원문 코퍼스의 '조용한 공백'을 닫고, 다음 스냅숏 갱신을 같은 절차로 반복할 수 있게 한다(원장·대조 스크립트를 저장소에 둔다). |

**목표 지표**
- 누락 26조문 중 노동 관련 11개(보류 7 + 임금채권보장법 4)가 `laborlaw-v2`에 실린다 — 원장 verify 통과, 조문 키 대조 재실행 시 누락 0(민사집행규칙 15는 §5 판단).
- 국민연금법 제126조가 현행판 본문으로 바뀌고 구 벡터는 삭제된다(고아 0).
- BM25 코퍼스 재빌드 후 문서 수가 (기존 − 대체 + 신규)와 정확히 일치, CI BM25 메모리 테스트 통과.
- 검색 회귀: `eval_retrieval.py`·`eval_corpus_mix.py --baseline` 수치가 기준선 대비 하락하지 않는다.

## 1. 출처와 현재 상태 (2026-11-12 확인)

- 법제처 조회는 등록 회선(현재 공인 IP)에서 동작한다. 같은 날 `check_law_freshness --anchors`는 26종 전부 기준일 시행판 반환·앵커 이상 없음으로 통과했다(calculator-statute-audit 잔여 ❌ 해소 — 그 보고서에 추기할 것).

## 2. 범위

**포함**
1. 이미지 보류 규칙 수정 — `조문내용`에 표 텍스트(`┌…┘` 상자)가 함께 있으면 `<img>` 태그만 걷고 표 텍스트를 본문으로 쓴다. 표 텍스트가 없고 이미지뿐이면 지금처럼 보류한다.
2. 법제처 현행판에서 대상 법령 7종(고용보험법 시행령·시행규칙, 국민건강보험법, 퇴직급여법 시행령, 임금채권보장법, 국민연금법 + 판단에 따라 민사집행규칙)을 다시 받아 대상 조문만 청크로 만든다.
3. 새 배치 `qpack_20261112_`로 적재(메타데이터는 기존 배치와 같은 스키마, `official: True`, `source_batch: sourcepack_20261112`) + 커밋 원장 `data/vector_ledgers/qpack_20261112.json`.
4. 국민연금법 제126조의 구 벡터(`qpack_20261009_` 해당 ID) 삭제 — 원장 `revision`에 대체 기록.
5. BM25 재빌드 → `data/bm25_corpus.jsonl.gz` 커밋.
6. 조문 키·본문 대조 스크립트를 저장소에 둔다(`check_source_pack.py` 가칭 — 팩 ↔ 현행판, 오프라인 모드는 저장본 대조).

**제외**
- 원본 팩 54문서 전체 재수집·재임베딩(바뀌지 않은 조문은 그대로 둔다 — 비용·위험 대비 이득 없음).
- 시행 예정 판본(12-08 이후).
- 행정규칙·판례·서식(보류 74건 중 권리 검토가 `hold`인 것)은 권리 판단이 다르다 — 이번 범위 밖.

## 4. 완료 조건

1. 대상 조문 12개(보류 7 + 신설 4 + 변경 1)가 `laborlaw-v2`에 현행판 본문으로 있고, 커밋 원장 verify 통과.
2. 조문 키 대조 재실행: 노동 관련 법령 누락 0, 본문 차이 0.
3. BM25 재빌드·커밋, CI 통과(BM25 메모리 포함).
4. `eval_retrieval`·`eval_corpus_mix --baseline` 기준선 대비 하락 없음.
5. CLAUDE.md의 `laborlaw-v2` 벡터 수·구성 서술 갱신.

## 5. Design에서 정할 것

- **Q1 민사집행규칙 제175조의2~16(가상자산 집행) 포함 여부** — 임금 강제집행 질문에 닿을 수 있으나 노동 상담 빈도는 낮다. 권고: 제외(다음 정기 갱신으로).
- **Q2 임금채권보장법 4조문의 본문 위치** — 현행판 XML에서 본문이 비어 보였다(조문 제목만). 하위 태그 구조를 확인해 실제 본문을 얻을 수 있는지, 아니면 법제처가 아직 본문을 싣지 않은 것인지 판정.
- **Q3 표 텍스트 채택 기준** — 상자 표 문자 비율·행 수 등 자동 판정 규칙과 사람 검토의 분담.
- **Q4 배치 방식** — 새 배치 + 구 ID 삭제(권고) vs 기존 배치 원장에 추가(같은 `qpack_20261009_` 접두사 재사용 — 원장 의미가 흐려져 비권고).
- **Q5 준비 스크립트 위치** — 저장소 밖 스크립트를 이번에 저장소로 옮길지(`source_pack_refresh.py`), 저장소 밖에서 돌리고 원장만 커밋할지.
