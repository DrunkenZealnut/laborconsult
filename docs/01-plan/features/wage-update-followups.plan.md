# wage-update-followups — Codex 계산기 갱신(PR #126~#132) 리뷰 후속 Plan

> 입력: 2026-10-25 Codex 계산기 갱신 리뷰(High 3·Medium 18·절차 지적). High 3건은 PR #134로 고쳐 머지·배포했다(`edaf904`). 이 Plan은 남은 Medium 18건, 리뷰에서 함께 나온 Low와 절차 지적, 그리고 이번 재현에서 새로 찾은 결함을 다룬다.
> 작성: 2026-10-26 · 단계: Plan · 기준: main `edaf904`
> 재현 방법: 모든 사례를 오프라인으로 실행했다(LLM·네트워크 없음). 채팅 경로 사례는 프로덕션 변환기를 그대로 거쳤다: 분석기 후처리 `_build_analysis_result` → `_analysis_to_extract_params` → `_run_calculator`. 수정 방향은 저장소 파일을 고치지 않고 메모리에서 함수만 바꿔 기존 테스트를 다시 돌려 확인했다. 재현 스크립트는 저장소 밖에 둔다.

## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 리뷰 지적 18건이 현재 main에 모두 남아 있다. 흔한 질문이 조용히 보류되거나 조용히 틀린다. 최저임금·퇴직금·4대보험 질문이 계산 유형 누락이나 지나가는 '연말정산' 한마디로 금액 없이 끝난다. 퇴직금 체불이자는 14일 기한 전부터 5%/6%를 붙인다. 2025년 육아휴직은 날짜를 줘도 '기준일 필요'로 보류된다. 기존 테스트는 이 가운데 하나도 막지 못한다. |
| **Solution** | 문서 PR 하나와 법 영역별 코드 PR 4개(카드·입력, 육아·출산, 체불, 연차)로 나눈다. 각 재현을 실패하는 테스트로 먼저 고정한 뒤 고친다. 법률 판단이 걸린 4건은 원문을 대조한 뒤 Design에서 확정한다: 변제 충당 순서, 육아휴직 출근 간주의 기준일, 난임치료휴가 3·4일째 상한, 퇴직금 지급기일. |
| **Function UX Effect** | 계산할 수 있는 질문에는 안내문 대신 금액 카드가 나온다. 한 카드 안에 평월 금액과 정산월 금액이 섞이지 않는다. 법적 근거 조문이 원문과 맞는다. 보류는 정보가 정말 없을 때만 난다. |
| **Core Value** | 대량 자동 구현이 남긴 '조용한 보류·조용한 오답'을 지적 단위로 닫는다. 각 지적을 테스트와 변이 검사로 고정해 다음 대량 변경에서 되풀이되지 않게 한다. |

**목표 지표**
- §2의 재현 사례가 모두 기대 동작으로 바뀐다. 각 사례는 `edaf904`에서 실패하고 수정 후 통과하는 오프라인 테스트로 고정한다.
- 살아남은 변이 11종(연차 M1~M8, 육아 M1·M2·M6)이 전부 검출된다.
- 대상이 아닌 입력의 수치는 바뀌지 않는다(골든·배선·CLI 116사례). 바뀐 사례는 전부 이번 지적의 입력이어야 하고, 그 목록을 Design에 남긴다.
- Live(`run_eval.py --law-mode prod`)에서 계산 fixture 2종의 금지 수치가 2회 모두 0이다.

## 3. 원인

1. **보류가 기본값인 경로가 많다.** 정보가 비거나 애매할 때 묻지 않고 넘어가거나(G1·G2), 반대로 계산 전체를 멈춘다(A3·P1·L3). '모름'과 '해당 없음'을 같은 값으로 다루는 기본값(A1의 `False`)도 같은 뿌리다.
2. **분석기 출력과 계산기 입력 사이에 대조가 없다.** 분석기가 채운 총액(G3)과 다태아 여부(P2)는 각각 검증 없이 들어가거나 아예 사라진다. 리뷰 테스트는 params를 손으로 만들어 이 변환을 건너뛴다(W13).
3. **같은 축을 두 번 센다.** 상여 중복 조정이 연장 가산까지 빼고(G4), 고정연장수당과 파생 연장을 함께 더한다(A5). 일할 정산액과 평월 금액이 한 카드에 섞인다(G5).
4. **법률 사실을 손으로 썼다.** 근거 조문(P3), 고시에 없는 상한(P4), 공개 화면 문구(A7·P6), 퇴직금 지급기일 규칙(A4)이 원문과 다르다.
5. **결과의 근거가 카드 밖에 있다.** 연차의 적용 제외 사유·전제·정산 시점이 breakdown에만 있어 답변이 그것을 모른다(L1·L4).
6. **테스트가 분기를 지키지 않는다.** 보류 여부만 단언하거나(P5), 경계를 다른 이유로 통과한다(L5). 변이 11종이 산다.
