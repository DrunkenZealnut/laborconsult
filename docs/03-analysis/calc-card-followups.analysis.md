## 4. 설계 공백 (설계가 다루지 않은 것 — Claude 확인 포함)

1. **[High] 공개 해고예고 흐름도가 F7과 반대다.** `public/calculator_flow/dismissal_notice_pay_calc.html`(사본 `wage_calculator/calculator_flow/` 같은 파일)은 다음과 같이 그린다. 카드(계산기)는 이번에 현행 제26조 단서 1~3호로 고쳤는데, `/calculators` 메뉴의 공개 페이지에 R16의 옛 오답이 그대로 남았다.
   - 흐름 노드가 '② 계절적 사업 4개월 이내', '④ 일용근로자 1개월 미만', '⑤ 수습 3개월 이내'를 면제로 그린다.
   - 안내 문구가 "수습 3개월 이내에 해고되면 예고수당을 받을 수 없습니다"라고 쓴다.
   - JS `else if(isProb){exempt=true}`가 근속 3개월 이상인 수습도 면제로 계산한다.
   - 설계 §3.10은 흐름도 두 개(주휴·포괄 역산)만 범위로 잡았다. **(Claude 확인)**
2. **[Medium] 따로 적힌 연장시간이 있는데 overtime이 계산 대상이 아니면 월 총액과 평균임금·보수가 갈린다.** §3.4는 파생 연장일 때만 overtime을 대상에 넣는다. 시급제·월급제에서 퇴직금이나 4대보험만 물으면 월 총액에는 연장이 빠지고 F6 소비처에는 들어간다. C9(H2)와 같은 유형이다. 코드를 읽고 추론한 결과라 재현을 먼저 해야 한다.
3. **[Medium] CLAUDE.md:926의 "1일 8시간을 넘는 입력(격일제 16시간 등)의 소정·연장 분리는 아직 없다"가 사실과 반대가 됐다.** §13은 기존 항목을 고치는 일을 다루지 않았다. **(Claude 확인)**
4. **[Medium] 주휴 흐름도의 정적 예시가 같은 페이지 JS와 R2에 반대다.** '주4일 × 10시간 (40h) → 주휴 = min(40÷5, 8) = 8시간'이 남아 있다(JS와 카드는 6.4시간). **(Claude 확인)**
5. **[Medium] 의도분석 도구의 `weekly_work_days`가 `integer` 타입이다**(`app/templates/prompts.py:45`). 실측에서 3.5가 그대로 들어온 것은 OpenAI가 타입을 강제하지 않아서다. 다른 제공자가 반올림하면 '평균 주 3.5일'이 3이나 4가 되어 주휴가 4.8h나 6.4h로 바뀐다(맞는 값 5.6h). C27 보강은 값이 없을 때만 돕는다. **(Claude 확인)**
6. **[Low]** split_hours의 소정근로일 상한 `min(…, days_in)`(평균 근무일수 5.8일 등)이 설계 식에 없다. §3.1에 반영할 것.
7. **[Low]** 다른 흐름도에 고정 8시간이 남아 있다: 실업급여 '하한 = 최저시급 × 80% × 8h', 퇴직금, 출산전후휴가. T15는 계산기 .py만 본다.
8. **[Low]** 규모 미상 경고가 overtime 대상에만 걸려, 포괄임금 역산만 도는 카드는 1.5 가산을 쓰면서 경고가 없다.
9. **[Low]** §12에 kin-19 매처의 부정어 '않' 오탐(§14.8)이 빠졌다. CLAUDE.md ③("WAGE_CALC_RULES가 조건부 산식으로 막는다")은 §14.8 실측과 맞지 않는다 — 미확인 모드의 '추정 금지'가 3.6을 막았다.
10. **[Low]** 낡은 문구: unemployment.py 머리 docstring의 '× 소정근로시간(8h)', 노무제공자 전용이 된 상수 주석, CLAUDE.md의 shared.py 설명(split_hours·monthly_pay_estimate 없음).
