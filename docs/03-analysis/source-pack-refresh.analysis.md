## 9. 설계 자체의 공백

| # | 공백 | 영향 | 권고 |
|---|---|---|---|
| G1 | 연산 기호 손실을 자동으로 찾지 못한다 | 중 | prepare가 상자 표 줄의 `?`를 `suspect_glyph`로 표시하고 review 표에 열을 추가한다 |
| G2 | D3 자기모순(공백 축약 vs 정렬 유지) | 낮음 | 설계를 "선 문자 유지, 행 안의 공백은 축약"으로 고친다 |
| G3 | 다단 상자 표의 열 순서가 섞이고, 표가 청크 경계에서 잘린다(제104조의2). 시행령 제8조는 분수를 `├──` 줄로만 나타내 나누기 기호가 없다 | 중 | 표를 한 청크로 묶는 가드를 두거나 헤더에 주석을 단다. 산식 질의로 실제 검색 결과를 확인 |
| G4 | fetch가 `legal_api.fetch_law_root()`의 게이트를 복제하면서 법령명 대조·폐지 거부를 빠뜨렸고, requests 예외를 `_exc_label`로 감싸지 않는다(`OC=` 노출 가능) | 중 | 게이트 함수를 공유하고, 예외는 클래스명·상태만 출력한다 |
