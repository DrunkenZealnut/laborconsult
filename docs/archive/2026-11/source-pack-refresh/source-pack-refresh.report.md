## 4. 설계에 없던 발견

1. **연산 기호 손실**(`?`) — D2의 전제("상자 표 텍스트가 산식을 담는다")가 일부 실패했다. 사람 검토만이 이를 잡았고 자동 탐지는 없다.
2. **supersede 멱등화** — 대체 뒤 재실행은 구 원장 `revision`에서 ID를 찾아 건너뛴다(테스트가 대체 전후 상태를 모두 본다).
3. **`official_url` 형식 차이** — 새 배치는 `/법령/{법령명}/({시행일})` 형식이라, url로 문서를 묶는 `legal_updates._document_key()`가 구·신 배치를 다른 문서로 볼 수 있다(영향 낮음).
4. **R5 기존 상태** — 최저임금 공식 2차 조회 상위 4슬롯에 고시 금액 문서(`official_`)가 없는 것은 10-09 팩 적재 때부터이고 이번 변경과 무관하다(CLAUDE.md 경고 그대로).

## 5. 교훈

- **"자료팩에 없다 ≠ 법에 없다"의 다음 단계: "텍스트가 있다 ≠ 산식이 온전하다."** 법제처 텍스트의 상자 표도 연산 기호를 잃을 수 있다. 산식 조문은 사람 검토 관문을 없애지 말 것.
- **스냅숏 갱신은 기존 원장을 고치지 않는다.** 새 배치 + 좁은 supersede + 구 원장 `revision` 기록이면 롤백 단위가 배치별로 분리된다.
- **Match Rate 90%가 "점검을 돌렸다"를 뜻하지 않는다.** v1.0은 회귀 측정·R5를 실행하지 않은 채 90.2%였다 — Plan 완료 조건을 따로 세어 보는 것이 그 공백을 드러냈다.
