## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 실질문 20건 중 1건이 54점이었다(조기재취업수당 7일/14일 혼동 + 틀린 입사일 조언). 4건은 이미 폐기된 기준을 현행처럼 안내했다(일용직 10일 미만, 주휴 '다음 주 근무 예정', 삭제된 근기법 제35조). 판례 인용은 "검색 결과에 있는가"만 검사해, 쟁점이 다른 판례(2018두63235)가 직접 근거처럼 실렸다. |
| **Solution** | ① 20건을 회귀 fixture로 고정한다. ② 현행 기준을 결정적 사실 블록으로 주입한다(`_KNOWLEDGE_MODULES`에 고용보험·해고예고·주휴 모듈 추가, 공식 원문 수집과 연동). ③ 폐기 기준이 담긴 상담 청크를 컨텍스트에서 걸러낸다. ④ 인용 판례와 질문의 쟁점 관련성을 검증한다. ⑤ 실행 조언·요약 일관성 규칙을 둔다. |
| **Function UX Effect** | 실업급여·주휴 질문에 현행 요건과 조문이 고정 문구로 나간다. 날짜·입사일 같은 행동 조언은 조건과 근거를 붙여서만 제시한다. 관련성 낮은 판례는 아예 빠진다. |
| **Core Value** | 이 서비스의 위험은 "모른다"가 아니라 **"틀린 것을 확신 있게 말한다"**이다. 그 실패의 원인은 코퍼스와 검증 계층에 있으므로 프롬프트 문구보다 구조로 막는다. |

**목표 지표**: 지식iN 20건 재평가 평균 78.4 → **≥ 88**. 폐기 기준·오조문(리포트 §4-A·B) **0건**. fixture의 `forbidden_claims` 적중 **0건**.

## 1. 리포트 리뷰 — 동의·보완·이견

리포트의 방법론(5영역 배점, 실재·관련성·미확인 3분리)은 타당하다. 특히 "허위 확정이 아니라 인용 보류"라는 구분은 이 시스템의 `citation_validator`가 갖지 못한 축이다. 보완점 셋:

1. **측정 조건이 현재 배포와 다르다.** 20건의 생성 시각은 10-02 14:08~14:19 KST이고, 전부 `claude-opus-5-5` 단독(폴백 0)이다. 이 시점은 PR #95(effort=medium + 추론 요약) **이전**이라 effort 미지정·기본 thinking 상태였다. 그래서 개선 전에 현 배포로 **재측정한 기준선**이 먼저 필요하다. 그래야 효과를 개선 조치 쪽에 귀속할 수 있다.
2. **"최신성"은 LLM 문제가 아니라 코퍼스 문제다**(§2 실측). 리포트 권고 1(시행일 확인)을 프롬프트만으로 이행하면 같은 컨텍스트가 같은 오답을 다시 만든다.
3. **권고 4(일관성 검사)는 범용 구현이 어렵다.** 요약과 표가 충돌한 8번은 범용 NLI보다 "수습 감액 >10%" 같은 **불변식 단정 금지**로 잡는 편이 비용 대비 확실하다(§3 P1-5).

## 2. 원인 분석 (실측 2026-10-03)

### 2.1 폐기 기준은 코퍼스에서 왔다

BM25 코퍼스(`data/bm25_corpus.jsonl.gz`, 81,184건) 정규식 집계:

| 패턴 | 출처별 건수 | 판정 |
|---|---|---|
| 일용 + "10일 미만"(구기준) | qa 6 | 폐기 기준 존재 |
| 일용 + "3분의 1"(현행) | **0** | **현행 기준이 코퍼스 어디에도 없다** |
| "다음 주 … 근무 예정"(구해석) | qa 25 · textbook 5 · interpretation 1 | 구해석이 압도적 |
| 근로기준법 제35조(삭제 조문) | qa 4 · precedent 5 · interpretation 2 · textbook 2 · regulation 1 | 판례는 당시 유효 — 역사적 인용 |
| 제26조 단서(현행) | textbook 7 · regulation 4 · counsel 4 · 기타 4 | 존재하나 소수 |
| 조기재취업 + 14일 / 7일 | qa 1 / qa 1 | 근거 빈약 — LLM이 제49조 대기기간으로 일반화 |

→ 일용직 3·18번 문항은 **검색이 정상 작동해도 구기준만 나오는 구조**다. 공식 원문 코퍼스(`official_` 18벡터)에는 고용보험법 제40조·제64조, 시행령 제84조가 없다.

### 2.2 인용 검증은 존재만 본다

- `validate_response_citations()`(`app/core/citation_validator.py:193`)는 `whitelist_hits` 포함 여부만 판정한다.
- 2018두63235는 코퍼스에 `crawlprec_2018du63235_*`(제목 "고용보험 가입 대상 공무원의 가입 시기")로 있어 **유효 처리됐다**. 쟁점이 달라도 통과한다.
- 2019다293449(19번)는 `citation_fixed` 기록이 없어 환각으로 감지되지 않았다. 즉 그 시점 `whitelist_hits`(법제처 라이브 조회 포함)에 있었는데, BM25 코퍼스에는 0건이다. 존재는 했지만 주휴수당 쟁점과의 관련성은 검증되지 않았다.
- 2010다111757은 코퍼스 0건이다. 원문 확인이 Design 단계 과제로 남아 있다.

### 2.3 계산·조건 규칙의 공백

- 조기재취업수당(제64조)·일용직 수급요건(제40조①5호)·상용직 판단 예외(제43조③ 단서)는 지식 모듈도 계산기도 없다. LLM이 기억으로 답하는 영역이다.
- 수습 감액 상한(최저임금법 제5조② 10%), 보복 처우 벌칙(제109조①)도 마찬가지다. 같은 답변 안에서 요약과 표가 갈렸다(8번).

## 3. 개선 항목 (우선순위)

### P0 — 이번 사이클 필수

**P0-1. 지식iN 회귀 fixture** (`data/eval_kin_queries.json`)
- 20문항 원문 + `required_laws`(예: 12번 `고용보험법 제64조`) + `forbidden_claims` + `required_notices`. `eval_consultation.py`가 그대로 읽는 스키마를 쓴다.
- ⚠️ `forbidden_claims`는 **부분문자열 매칭**이라(`eval_consultation.py:259`) "10일 미만"을 넣으면 "구 기준 10일 미만은 폐지됐다"는 정답도 감점한다. 폐기 단정형 문구를 좁게 쓰거나, 부정 문맥 예외를 매처에 추가한다. 방식은 Design에서 확정한다.
- 먼저 **현 배포(effort=medium)로 기준선을 재측정**하고 그 결과를 `docs/04-report/consultation-eval-baseline.md`에 지식iN 절로 추가한다.

**P0-2. 현행 기준 사실 블록** — `_KNOWLEDGE_MODULES`(`pipeline.py:1081`)에 등록한다.

| 모듈 | 내용 | 근거 |
|---|---|---|
| `고용보험수급` | 일용 수급요건(전월 초일~신청일 근로일수 1/3 미만, 건설일용 14일 무근로 대안) · 대기기간 7일(제49조) · **조기재취업수당 = 실업신고일부터 14일 경과 후 재취업**(제64조, 시행령 제84조) · 상용직 판단 예외 조건(제43조③ 단서) · 취업지원 교육 후 14일 내 신청 | 고용보험법·시행령 |
| `해고예고` | 3개월 미만 예외 = 제26조 단서 제1호. **제35조는 삭제됨** | 근로기준법 |
| `주휴` | 2021-08-04 변경 해석: 해당 1주 근로관계 존속 + 개근이면 다음 주 근무 예정과 무관하게 발생 · 4주 평균 15시간(제18조③) | 근로기준법, 고용노동부 해석 |
| `수습감액` | 1년 이상 계약 + 3개월 이내 + 단순노무 제외 → **최대 10%** | 최저임금법 제5조② |

- 문구는 `fetch_official_rules.py` 대상에 해당 조문을 추가 수집해 **원문 대조 테스트**로 고정한다. 손으로 쓴 사실문이 조문과 어긋나면 결정적 오답이 된다.
- 감지 조건은 `_wants_minwage_facts`와 같이 의도분석 결과 + 키워드로 둔다. 무관한 질문에 실리면 컨텍스트 잡음이 된다.

**P0-3. 폐기 기준 청크 필터** — `conflict_resolver.annotate_source_priority()` 단계에 둔다.
- `STALE_RULES` 레지스트리: (패턴, 폐기일, 대체 기준). **qa/counsel 청크는 컨텍스트에서 제외**하고, 판례·행정해석·해설서는 제외하지 않고 `[구 기준 — YYYY-MM-DD 이후 변경]` 주석을 붙인다. 판례가 제35조를 인용한 것은 당시 유효한 법리라 지우면 근거가 사라진다.
- 오억제 위험: "10일 미만"이 다른 문맥(연차 등)에도 쓰이므로 패턴은 공기어 창(일용 ±40자)을 필수로 한다. 영향 청크 수를 dry-run으로 먼저 집계한다(§2.1 기준 qa 31건 내외).

### P1 — 같은 사이클 권장

**P1-4. 인용 관련성 검증**
- 유효 판정된 판례마다 해당 hit의 제목·판시사항과 **질문**의 임베딩 유사도를 계산한다(`case_match.py`의 임베딩 경로 재사용, 배치 1회).
- 임계 미만이면 기존 교정 경로(`correct_hallucinated_citations`)에 "관련성 낮음"으로 넘겨 삭제한다. 임계는 fixture로 측정해 정하며, 2018두63235(11번)는 걸리고 2020다270503(9번)은 통과해야 한다.

**P1-5. 불변식 단정 금지 규칙** — `WAGE_CALC_RULES`와 같은 방식으로 두 답변 분기 모두에 접미한다.
- "수습 감액 10% 초과는 어떤 경우도 적법하지 않다", "필수요건이 불분명하면 성립 가능성을 '높다'고 단정하지 않는다" 등. 범용 일관성 검사 대신 리포트가 지목한 실패만 정확히 막는다.

**P1-6. 실행 조언 규칙** — 입사일·퇴사일·신고일 변경 조언은 (a) 근거 조문 (b) 기산 방식 (c) "고용센터 확인 필요"가 함께 있을 때만 쓴다. 날짜 하나만 권고하는 형식은 금지한다(12번의 "10/14 입사" 유형).

### P2 — 후속

- 리포트 권고 3(조건 체크리스트)을 의도분석의 `missing_info`와 연결해 결론 전 확인 질문으로 만든다.
- `qa` NS의 폐기 기준 원문을 재임베딩 대상에서 영구 제외한다(P0-3은 런타임 필터라 BM25 재빌드가 필요 없다).
- 리포트 §4-D 청년지원사업 제외조건 — 연도별 공고 의존이라 사실 블록 대상이 아니다. "공고 확인" 고지로만 처리한다.

## 4. 범위 밖

- 범용 요약↔본문 NLI 일관성 검사(비용 대비 효과 불확실, P1-5로 대체)
- 판례 원문 실재 확인을 위한 법제처 라이브 조회 추가(현 validator가 법제처 결과를 이미 whitelist에 포함)
- 모델 교체(20건 모두 단일 모델·폴백 0이라 모델 비교 근거 없음)

## 5. 위험

| 위험 | 대응 |
|---|---|
| 사실 블록 문구 자체가 틀림 → 결정적 오답 | 공식 원문 수집 + 원문 부분문자열 대조 테스트 |
| 폐기 필터 오억제로 유효 상담 근거 소실 | 공기어 창 필수 + dry-run 집계 + 킬스위치 `STALE_FILTER=off` |
| 관련성 임계 과민 → 정당한 판례 삭제 | fixture 양·음성 사례로 임계 결정, 초기 `monitor`(기록만) 배포 |
| fixture 부분문자열 매칭 오탐 | 부정 문맥 예외 또는 단정형 문구만 사용 |
| 법 개정 시 사실 블록 낡음 | 모듈마다 `as_of`·근거 조문 표기, `check_law_freshness.py` 대상에 조문 추가 |
