## 4. 테스트 공백 (참고, 점수 미반영)

- **헤더 전 abort**: L14의 abort는 `readSSE` 모의에서만 일어난다. fetch 모의가 바로 resolve하므로, 콜드 스타트 중(응답 헤더 전) fetch가 거절되는 경로는 vm에서 돌지 않는다. → §7에서 닫음.
- **`activeSend` 정리 줄**: `if (activeSend === ctrl) activeSend = null;`(1861)을 단언하는 테스트가 없다. 지워도 끝난 컨트롤러에 대한 `abort()`는 아무 일도 하지 않으므로 해는 없다.
- **재현 불가한 기록**: 변이 22/22, CI 28단계, 브라우저 확인은 저장소 밖 스크립트의 실행 기록이다. 이번 분석에서 확인한 것은 노드 테스트 직접 실행(16/16, 33/33)과 M1~M13 정적 추적이다.
