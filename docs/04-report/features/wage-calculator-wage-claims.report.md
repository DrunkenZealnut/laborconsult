## 변경 내용

확정된 월별·항목별 지급 의무액과 기지급 원금을 대조한다. 세전 의무액에서 세후 통장 입금을 바로 빼지 않으며, 지급 귀속이 불명확하면 충당 내역을 요구한다. 초과 지급은 별도 표시하고 다른 항목과 자동 상계하지 않는다.

통상시급·실제 월 연장/야간/휴일 시간·확정 주휴 주 수·최저임금 보충·C6 일할 결과를 재사용한다. 연 상여의 월 환산액을 실제 월 채권으로 만들지 않는다. 포함된 임금 요소와 산출 출처의 중복을 검사한다. 추정 월액은 명시적으로 표시하고 확정 이자 채권으로 넘기지 않는다.

C2에는 원래 의무액과 실제 변제 이력을 넘긴다. 전액 지급했어도 지연 지급 이자는 남을 수 있다. 지급 날짜·이자 충당·제외 기간의 귀속을 모르면 확인 가능한 원금은 유지하고 이자만 보류한다. 별도로 요청한 기존 체불 채권의 이자는 독립 계산한다.

근거: [민법 제476~479조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032404465), [법제처 생활법령 최저임금법 제6조 안내](https://easylaw.go.kr/CSP/CnpClsMainPreview.laf?ccfNo=1&cciNo=2&cnpClsNo=3&csmSeq=1694&popMenu=ov). 이율·퇴직 지급기한·제외 기간은 C2의 검증된 계약을 재사용한다.

## 독립 리뷰와 수정

최초 `23e358f`에서 Important 10개, Critical 0개. 한 번의 RED→GREEN 수정 과정으로 아래를 보강했다. 별도 재리뷰를 반복하지 않았다.

1. 퇴직 지급기한이 원래 지급일보다 빠른 채권도 체불 원금·이자에 반영하고 두 날짜를 표시.
2. 주휴 출근 일수·고정수당·월 총액·이자 의존 필드를 분석/대체 추출부터 입력 모델까지 전달.
3. 미개근 주를 확정 주휴 채권으로 만들지 않도록 자격 확인.
4. 파생 채권의 누락 임금·수당 환산용 근로시간을 보류. 확정 명세의 독립 계산은 유지.
5. 월 전체 금액에 포함된 고정연장·상여 등 요소를 자동 중복 검사.
6. 최저임금 위반 여부와 부족 금액의 확정 여부를 구분. 미확인 수습 요건 등으로 금액이 갈리면 보류.
7. 원본 금액 검증과 확정 사업장 규모·정규화된 근로시간을 함께 사용.
8. 상위 이자 제외 기간을 조용히 버리지 않고 항목별 귀속 확인 전 이자 보류.
9. 새 원금 명세와 별개인 기존 C2 요청을 보존. 관계 미확인은 보류.
10. 정산 추출에 제한된 8,192~32,768 출력 예산을 주고 Claude/OpenAI/Gemini의 토큰 한도 종료를 실패로 처리. 일부 잘린 명세를 완전한 정산으로 채택하지 않음.

지적별 재현 실패와 수정 통과 로그를 보존했다. 토큰 종료 검사는 기존 코드에서 세 공급자 모두 실패함을 별도로 확인했다.

Minor 1개는 후속으로 남겼다: C5 카드에 최종 의무액−지급액은 표시되지만 출처별 시간·시급·주 수·일할 비율의 상세 전개는 모두 표시하지 않는다. 원본 항목 ID와 계산 기초는 유지된다.
