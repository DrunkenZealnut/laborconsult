## 변경

- 현행 사건에서 첫해 사용분을 다음 연도 15일에서 빼던 계산을 제거했다. 첫해와 당해 발생·사용·잔여를 별도로 표시한다.
- 실제 개근 개월, 법정 출근 간주 기간, 마지막 재직일, 단축 전 근로시간, 실제 사용시간을 분석부터 계산까지 전달한다. 필요한 자료가 없으면 해당 계산을 보류한다.
- 단시간 연차를 시간으로 계산하고 시간 단위 올림을 적용한다. 출근율 80% 미만인 1년 이상 근로자의 개근분은 다음 연도에 발생하도록 반영했다.
- 달력상 근속연수와 정확히 1년 종료 계약을 구분한다. 과거 제도는 확인한 적용 범위에서만 계산하고, 과거 출근·시간 자료가 없는 일정은 조건부 참고값으로 표시한다.
- 현재 잔여분의 임금 평가액과 실제 정산 시점을 구분한다. 공개 설명·시뮬레이터와 사본을 함께 수정했다.

입력 계약과 공식 원문·해시는 [설계 기록](../../02-design/features/wage-calculator-annual-leave-update.design.md)에 정리했다.

## 실제 답변 비교

합성 fixture의 5개 질문을 수정 전후 각각 2회 실행했다. 최종 답변 10건을 직접 읽고 계산 카드와 대조했다.

| 사례 | 수정 전 | 최종 수정 후 |
|---|---|---|
| 첫해 사용분의 다음 연도 차감 여부 | 차감하지 않는다는 법률 안내 2/2 | 동일하게 유지 2/2 |
| 당해 15일 발생·2일 사용 | 사용분 누락, 잔여 15일 2/2 | 잔여 13일·104시간·평가액 104만 원 2/2 |
| 출근율 70%·개근 7개월·2일 사용 | 출근율·사용분 누락, 잔여 15일 2/2 | 발생 7일·잔여 5일·평가액 40만 원 2/2 |
| 법정 육아휴직 100일 + 실제 출근 150일 | 기본 출근율로 15일 2/2 | 명시 출근 간주 입력을 반영하여 15일 2/2 |
| 정확히 1년 종료·미사용 11일 | 11일·88만 원 2/2 | 마지막 재직일·정산 상태를 구분하며 동일 금액 2/2 |

금액은 fixture의 통상시급 1만 원 조건이다. 최저임금 적용과 실제 정산 시점은 별도 확인 사항으로 안내했다. 잘못된 카드가 관찰된 두 질문은 4/4에서 0/4로 감소했고, 최종 파이프라인 오류는 0/10이었다. 법률 안내만 하는 첫 질문과 기존에 맞던 두 질문을 개선 건수로 세지 않았다.
