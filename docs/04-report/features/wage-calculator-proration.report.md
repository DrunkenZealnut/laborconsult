## 변경 내용

정산월과 실제 입사일을 분리하고, 마지막 재직일은 포함·퇴직 효력일은 제외한다. 확정 무급 기간의 중복·월 밖 날짜를 제거한다. 달력일수 또는 명시된 소정근로일·유급 처리일 약정으로 계산하며, 지급 조건이 없는 항목은 보류한다.

전체 월액 비례 약정과 항목별 비례·전액·실제 지급 명세를 구분한다. 연 상여의 통상임금 월 환산액을 실제 월 지급 채권으로 바꾸지 않는다. 결과에 포함·제외 날짜, 비율, 항목별 금액을 보존하고 평소 월급·별도 연장수당을 정산액에 자동 가산하지 않는다.

공개 HTML 두 사본을 일치시켰다. 직접 계산 화면은 전체 월액에 같은 비율을 적용하는 약정을 확인받으며, 정산월·종료일 의미·무급 기간·유급 대상 날짜를 입력받는다. 항목별 조건이 다른 명세는 상담 계산 경로에서 지원한다. 보험료에 임금 일할 비율을 곱하던 공제·실수령액 추정을 제거했다.

근거: [고용노동부 1350 일할계산 안내](https://1350.moel.go.kr/rtmview.do?id=1000059852). 하나의 일할 방법을 법정 기본값으로 가정하지 않는다.

## 독립 리뷰 반영

`ab1f83e`에서 Important 6개, Critical 0개. 한 번의 수정 과정에서 다음을 RED→GREEN으로 검증했다.

1. 직접 호출의 음수 월액이 0원 성공으로 바뀌지 않도록 원본 계약 금액을 검증.
2. 실제 독립 항목 명세가 있을 때만 무관한 미확인 수당을 분리. 전체 월액의 미확인 수당은 보류.
3. 주 근로일수만 알려져도 날짜 기반 일할계산은 실행.
4. 일할계산 단독 요청에 합성 월 연장수당·임금 구성 추정이 붙지 않도록 수정. 명시적으로 요청한 연장수당 비교는 유지.
5. 공개 화면·두 사본·브라우저 산식 갱신.
6. 분석기 장애 시 대체 추출 도구에도 동일 입력 필드 연결.

Minor인 예전 ‘중도퇴사 미지원’ 문구도 수정했다. 별도 재리뷰를 반복하지 않고 전체 회귀·실제 답변으로 확인했다. C5 채권 생성·변제충당과 퇴직 최종 합산은 후속 범위다.

실제 질문의 중간 평가에서는 분석기가 월급을 전체 월액과 같은 단일 항목으로 중복 추출하는 문제가 발견됐다. 금액·주기·비례 정책이 동일한 단일 항목만 한 번 계산한다. 서로 다른 조건이나 여러 항목은 보류한다. 단일 월급액에 일할 약정을 명시한 질문은 그 금액의 약정으로 해석하며 미확인 추가 수당은 생성하지 않는다.
