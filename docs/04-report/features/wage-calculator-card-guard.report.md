## 변경

- 실행한 계산과 보류한 계산을 결과에 구분한다. 요청 계산이 모두 보류되면 통상시급·월급·실수령액을 해당 요청의 계산 결과처럼 표시하지 않는다.
- 연말정산, 선택근로 정산, 체불 원금, 현재 지원하지 않는 중도퇴사 정산의 요청을 보존한다. 복합 질문에서 완료된 독립 계산은 유지한다.
- 유형 별칭·복합 표현·부정 문장·플랫폼 입력 필터와 분석 메타데이터 전달을 함께 검증했다.
- 기존 금액 산식은 변경하지 않았다. 연차·육아급여·체불이자 등은 후속 릴리스다.
