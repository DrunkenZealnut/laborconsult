## 변경 내용

- 정기지급일 다음 날의 지급사유로 2025-10-23 개정 적용 여부를 판정한다. 기존 체불금은 시행일 도래만으로 20%로 전환하지 않는다.
- 퇴직 효력일·마지막 재직일·14일 지급기한을 구분하고, 이미 발생한 정기임금 20% 기산일을 퇴직 후 다시 정하지 않는다.
- 채권별 잔액·부분 원금 변제·법정 제외 기간을 나눈다. 상인 여부 미확인은 민사 5%와 상사 6% 조건별 금액으로 표시한다.
- 누적 발생 이자, 기지급 이자, 남은 이자를 구분한다. 부분 지급의 이자 충당액이 불명확하면 원금과 누적 이자는 유지하고 남은 이자·청구 합계만 보류한다.
- 분석 스키마·변환·facade·자동 감지·공개 HTML을 연결했다. 비근로자 용역비에는 근로기준법의 20%를 확정 적용하지 않는다.
- 윤년의 3년 도달일 예외를 제거하고, 단순 시효 날짜로 권리 소멸을 확정하지 않는다.

공식 법령 판본·시행일·부칙·원문 해시는 [구현 계약](../../02-design/features/wage-calculator-arrears-interest.design.md)에 기록했다.

## 독립 리뷰

다음 Important 3건을 실패 테스트로 재현한 뒤 수정했다. 후속 독립 리뷰는 22개 테스트와 직접 호출을 확인했고 잔여 Important 없음을 보고했다.

1. 이미 지급한 이자가 청구 합계에 다시 포함됨 → 지급 이자 충당액과 잔여 이자 분리, 미확인 합계 보류.
2. 비근로자 용역비에 새 20%가 적용됨 → 파이프라인과 직접 facade 호출의 적용 범위 보호.
3. 채권 목록·퇴직급여 날짜 입력이 자동 감지에서 누락됨 → 신규 입력과 잘못된 명시 입력을 검증 경로로 연결.

## 사용 범위

확정된 근로자 임금·퇴직급여 일시금의 단리 추정이다. 판결·약정·소송촉진법·DC 부담금 이율, 법적 제외 자격이 불명확한 사건은 별도 확인한다. 퇴직 지급기한은 토·일요일과 제공된 공휴일을 조정하며, 공휴일 목록 미확인은 조건부 날짜로 표시한다. 공개 화면은 부분 지급·제외 사유 없는 단일 채권을 다루고, 서버는 복수 채권과 구간별 내역을 지원한다.

main 병합·운영 배포는 하지 않았다. 다음 단계는 C4b 지급 주기·평균임금·기존 휴가 입력 연결이다.
