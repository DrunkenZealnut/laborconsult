# C6 정산월·항목별 일할계산 설계

> 2026-10-24 · P1-A · C4b 이후 구현 · 확정 계획 C6의 입력 계약

## 근거와 범위

월급의 일할 방법은 법령에 하나로 정해져 있지 않다. 약정한 달력일수 방식 또는 소정근로일·유급 처리일 방식으로 계산한다. 결근 한 번을 이유로 주휴일까지 자동 공제하지 않으며, 실제 무급 처리일이 확정돼야 한다. [고용노동부 1350 일할계산 상담](https://1350.moel.go.kr/rtmview.do?id=1000059852)

이번 결과는 지정 월의 세전 임금이다. 퇴직 최종 정산은 이 월급 명세에 미사용 연차·퇴직급여·공제를 별도 항목으로 연결하는 후속 합산으로 설계한다. C5는 이 명세를 미지급 원금의 지급 의무액으로 재사용한다.

## 입력 계약

| 필드 | 의미 |
|---|---|
| `settlement_month` | 정산 대상월 YYYY-MM. 입사월·오늘 날짜로 대체하지 않는다 |
| `proration_method` | `calendar` 달력일수 또는 `scheduled` 소정근로일·유급 처리일. 미확인은 보류 |
| `join_date` / `start_date` | 실제 입사일. 둘 다 주면 같아야 한다 |
| `last_employed_date` | 마지막 재직일, 그 날 포함. 마지막 출근일과 구분 |
| `proration_retirement_effective_date` | 퇴직 효력일, 그 날 제외. 마지막 재직일과 함께 주면 하루 차이 검증 |
| `proration_employed_at_month_start` | 입사일 없이 월초부터 재직 중이었다는 명시 확인. true일 때만 월초부터 계산 |
| `proration_unpaid_periods` | `{start,end,reason,confirmed}` 목록, 양끝 포함. 확정된 무급 기간만 차감; 중복은 날짜 집합으로 한 번 반영 |
| `proration_scheduled_dates` | scheduled 방식의 해당 월 전체 분모 날짜 목록. 약정에 따른 소정근로일과 유급 처리일 포함; 단순 평일 추정 금지 |
| `proration_all_items_proportional` | 전체 월액을 같은 비율로 일할한다는 약정의 명시 확인. true일 때만 공통 기준 월액 사용 |
| `proration_items` | 명시된 항목별 지급 조건과 금액. 아래 계약 적용 |
| `proration_items_complete` | 항목 목록이 요청한 월 정산 범위 전체라는 확인. 누락 항목을 0원으로 가정하지 않는다 |

항목은 `{id,name,amount,payment_cycle,policy,actual_amount}`. `policy`는 `prorate`(비례), `full`(이 달 전액 지급 확인), `actual`(별도로 산정·확정된 실제 금액)이다. actual은 `actual_amount`가 필수다. 월 급여 비례 항목은 매월 금액만 받는다. 연·분기 상여는 통상임금 월 환산액을 지급 채권으로 바꾸지 않고, 지급 대상월과 전액 지급 조건이 확인된 full 항목 또는 실제 정산액으로 입력한다.

전체 월액 일할 약정이 확인된 경우 `shared.monthly_wage_total`을 사용하되, 연·분기 수당이 있으면 해당 월의 지급 명세를 요구한다. 항목별 입력과 전체 월액 입력을 동시에 합산하지 않는다. 항목 식별자는 중복을 거부한다. 음수·무한대·boolean 금액, 잘못된 날짜, 앞뒤가 뒤집힌 재직 기간, 상충한 날짜는 보류한다.

## 산정과 결과

1. 정산월의 날짜 집합을 구한다.
2. 입사·마지막 재직일로 해당 월 재직 날짜를 제한한다. 퇴직 효력일은 전날까지 포함한다.
3. 확정된 무급 날짜를 한 번 제외한다. 휴직 종료일 다음 날부터 복직한 경우 그 날짜부터 포함된다. 월 밖 무급 기간은 교집합만 반영한다.
4. calendar는 월 전체 역일을 분모로, scheduled는 제공한 월 전체 유급 대상 날짜를 분모로 한다. 분자는 그 중 재직·유급인 날짜다.
5. 항목별 계약 금액에 정책을 적용하고 원 단위로 반올림해 합산한다. 분자·분모·포함 날짜·제외 날짜·항목별 금액을 결과에 보존한다.

정산액은 `prorated_wage`, 항목 내역은 `item_rows`로 제공한다. C5는 이 항목의 식별자·금액·정산월을 사용하고 지급기일·기지급 내역은 별도로 받아 채권을 만든다. 같은 월에 여러 질문으로 나눠 입력해도 정산 원금은 항목 ID로 중복을 판별한다.

일할계산만 요청한 카드에 평소 월급 총액·실수령액을 붙이지 않는다. 방식·계약 범위가 없으면 C4a의 보류 표시와 필요한 입력을 유지한다. 보험료·퇴직금 등 독립 요청의 결과를 월 급여에 자동 가산하지 않는다.

## 검증 계약

- 달력일수, 월급 300만 원, 마지막 재직일 2026-10-16: 16/31, **1,548,387원**.
- 같은 날짜가 퇴직 효력일이면: 15/31, **1,451,613원**.
- 윤년 2024-02-15 입사: 15/29. 같은 달 입퇴사·30일 월·31일 월.
- 월초부터 재직, 무급 휴직·결근·복직 및 중복 기간: 유급 날짜를 정확히 출력.
- 기본급 비례 + 식대 전액 + 실제 근로수당 별도: 항목별 합계 대조, 연 상여 월 환산분 자동 청구 금지.
- scheduled는 사용자 확인 날짜 목록만 사용. 목록 누락·중복·다른 월·역전·잘못된 날짜 보류.
- 분석 스키마 → 정규화 → 계산기 → 카드. 퇴직일 의미 미확인·방식 누락·지급 조건 미확인 반례.
- 기존 CLI·골든·배선·카드·월액·법률 갱신 검사, 실제 질문 변경 전후 각 2회, 독립 리뷰.

## 구현 순서

1. 실패 회귀와 자연어 fixture, 기준선 기록.
2. 엄격한 기간·항목 파서 및 계산, 전체 월액 계약과 기존 함수 연결.
3. 분석·파이프라인·registry·카드 연결과 날짜 의미 설명.
4. 회귀검사·실제 답변 비교·독립 리뷰, 보고서·PR.

## 독립 리뷰 후 보완

- 단일 월급액과 그 금액에 적용할 일할 약정을 명시한 질문은 해당 금액 전체의 비례 약정으로 해석한다. 미확인 수당을 만들어 넣지 않으며, 항목별 조건이 다르거나 미확인이라고 명시된 경우 전체 비례로 추정하지 않는다.
- 전체 월액과 동일한 금액·매월 주기·비례 정책의 단일 항목이 중복 추출되면 한 번 계산한다. 서로 다른 금액·정책이나 여러 항목은 보류한다. 빈 항목 목록은 없는 것으로 처리한다.
- 공개 화면은 전체 월액에 같은 비율을 적용하는 약정을 직접 확인받는다. 정산월, 입사일, 종료일 의미, 확정 무급 기간, 유급 대상 날짜 목록을 입력받고 세전 정산액을 표시한다. 항목별 다른 지급 조건은 상담의 항목 명세로 처리한다. 보험료에 임금 비율을 곱한 추정 공제·실수령액은 표시하지 않는다.
- 직접 호출의 음수 월액도 보류하며, 독립 항목 명세는 무관한 기준급 오류와 분리한다. 일할계산만 요청하면 일정에 연장시간이 있어도 별도 월 연장수당·구성 추정을 만들지 않는다. 대체 추출 스키마도 동일 필드를 제공한다.
