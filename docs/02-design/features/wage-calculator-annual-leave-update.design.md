# 연차 계산 갱신 C3 — 입력·결과 계약

> 2026-10-24 · 계산기 갱신 계획 v1.1의 P0-B · 기준 코드 ffce6f9

## 적용 범위

- 근로기준법상 5인 이상, 4주 평균 주 소정근로 15시간 이상. 제외 판정 0과 자료 부족 보류를 구분한다. 별도 약정휴가는 자동 부정하지 않는다.
- 첫해 월별 개근 휴가와 최초 1년 후 발생 휴가를 구분한다. 2017-05-30 이후 입사자의 첫해 사용분을 다음 연도 15일에서 공제하지 않는다.
- 과거 첫해 공제는 확인된 2014-07-01 시행판 및 법제처 해석에 한정한다. 그 이전 발생분의 확정 계산은 보류한다.
- 근속은 달력상 대응일을 사용한다. 윤년을 365일로 나누어 1년 완료로 판단하지 않는다. 대응일 없는 달은 민법 제160조에 따라 말일이 끝난 다음 날 권리가 발생한다.
- 별도 연차발생 모듈은 만들지 않고 기존 annual_leave를 갱신한다. 2026-03의 별도 모듈 계획에 남은 현행 차감·80% 미만 0일 가정은 이번 검증된 계약으로 대체한다.

## 입력

기존 WageInput 및 분석 도구에서 아래 필드를 같은 의미로 사용한다. analyzer → 정규화 → pipeline → 계산기에서 누락시키지 않는다.

| 입력 | 의미 |
|---|---|
| start_date, end_date | 입사일, 조회 종료일. 연차에서 종료일은 그 날의 재직 여부를 임의로 바꾸지 않는다 |
| last_employed_date | 근로관계가 존재한 마지막 날(포함). 일반적인 “퇴사일”에서 하루를 추정하지 않는다 |
| attendance_rate | 산정기간 일수 기준 출근율. 단축시간을 결근일로 환산하지 않는다 |
| annual_full_attendance_months | 해당 산정기간의 실제 개근 개월 수. 첫해 및 연간 80% 미만에 사용 |
| annual_scheduled_days, annual_attended_days | 소정근로일수와 출근 간주를 더하기 전 출근일수. 역일수로 대체 금지 |
| annual_deemed_periods | 사유·시작/종료일·휴직 중 소정근로일수·육아휴직 최초 신청일. 중복 구간 거부 |
| annual_original_weekly_hours, annual_original_daily_hours | 법정 단축 전 기준 소정시간 |
| annual_leave_used / annual_leave_used_hours | 현재 발생분의 사용 일수 / 실제 차감 시간. 시간이 있으면 시간 우선 |
| first_year_leave_used, first_year_full_attendance_months | 과거 첫해의 사용분·개근 수. 현재 출근율로 과거 개근을 만들지 않음 |
| use_fiscal_year, fiscal_year_granted_days | 회사가 회계연도 기준으로 실제 부여한 휴가. 입사월만으로 회사 정책을 지어내지 않음 |

출근 간주 사유는 업무상 부상·질병, 법정 출산전후휴가, 육아휴직, 단기 육아휴직, 육아기·임신기 단축이다. 일반 결근은 출근 간주 목록에 넣지 않는다. 월별 개근 수는 출근 간주를 반영한 실제 수치다.

휴직 구간이 산정기간 밖까지 걸치면 해당 산정기간의 구간과 소정일수를 나눠 요청한다. 단축은 원래 시작일을 보존하여 2024-10-22 이전 시작분을 새 규칙으로 바꾸지 않는다. 종전 단축의 복수 소정시간 정산은 추가 자료가 필요한 명시 보류다.

회계연도 정책은 법정 단일 산식이 아니다. 실제 회사 부여분을 받아 잔여를 산출하고 퇴직 시 누적 대조를 안내한다. 과거 출근·사용·기지급 자료 없이 기존의 “현재 기간끼리 차이 = 퇴직 추가 지급”은 산출하지 않는다.

## 결과와 호환

- 기존 accrued_days / used_days / remaining_days / annual_leave_pay를 유지한다. accrued_hours / used_hours / remaining_hours / day_hours를 추가하여 일수 단위를 표시한다.
- 단시간 연차는 시행령 별표2에 따라 시간으로 계산하고 1시간 미만 올림한다. 첫해 월별 발생은 각 월에 독립적으로 적용한다. 1년 이상 출근율 80% 미만자의 개근 월 수에 따른 휴가는 다음 연도에 일괄 발생하므로 그 일괄 발생분의 시간을 올림한다.
- annual_leave_pay는 입력 시급에 따른 현재 미사용분의 평가액이다. 사용기간이 남으면 확정 지급채권이라고 설명하지 않는다. 실제 퇴직·만료 당시 임금, 사용촉진, 귀책, 이월, 기지급 여부는 정산 전 확인한다.
- first_year_*는 별도 장부다. 첫해 사용 None과 실제 0을 구분한다. 개근 개월 수를 근로자의 발생시간·사용시간·일수로 환산하며 현재 소정시간이 첫해에도 같았다는 조건을 표시한다. 현재 연도 수당에 자동 합산하지 않는다. 첫해 월별 개근·사용 귀속이 없으면 그 정산분만 미확정으로 남긴다.
- schedule의 conditional=true 행은 과거 출근·시간을 확인하지 않은 참고값이다. 현재 출근율 하나를 모든 과거 연도에 실제 기록처럼 복제하지 않는다.
- 출근율 80% 미만은 전년도 개근 개월 수로 수량을 계산하고 다음 연도에 발생한다. 입사일 기준 발생일·소멸일을 함께 제시한다. [법제처 24-0674](https://opinion.lawmaking.go.kr/nl4li/lsItptEmp/444315)의 나 항을 따른다.
- BaseCalculatorResult.held_reason은 필수 사실 부족을 표시한다. facade는 해당 계산을 완료 목록에 넣지 않고 C4a 보류 카드로 전달한다. 자격 미적용 0은 정상 판정으로 유지한다.
- 공통 EffectiveRule / RuleSlice 도구는 반개구간 분할만 수행한다. 법률별 적용례·월차·자격은 호출자가 판정한다. 새 연차 규칙은 내장 규칙이며 기존 관리자 승인 키를 추가하지 않는다.
