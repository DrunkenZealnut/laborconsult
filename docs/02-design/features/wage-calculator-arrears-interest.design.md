# 체불 지연이자 구현 계약

> 2026-10-24 · C2 / P0-D · 구현 계약 확정 · 기준 `db58a80`

## 계산 범위

확정 원금의 이자를 채권별로 계산한다. 새 체불 원금 산정은 C5에 둔다. 기존 단일 원금 호출은 같은 채권 계산 함수에 위임하고, 복수 원금은 각각의 지급기일·변제·제외 기간을 보존한다.

- 재직 중 임금은 제43조의 정기지급일 다음 날이 2025-10-23 이후이면 연 20% 적용 대상이다. 2025-10-22 지급기일은 포함한다. 더 이른 채권은 시행일 도래만으로 전환하지 않는다.
- 이미 정기지급일에 근거한 20%가 발생한 채권은 퇴직해도 기산일을 다시 정하지 않는다.
- 임금과 퇴직급여 일시금을 구분한다. 퇴직 여부 boolean은 날짜를 대체하지 못한다. 마지막 재직일과 퇴직 효력일의 의미를 구분해 14일 경과를 계산한다.
- 20% 적용 전·법정 제외 기간에는 민사/상사 이율을 구분한다. 채무자의 상인 여부가 없으면 5%와 6%의 조건별 내역을 모두 내고 하나의 확정 금액을 고르지 않는다.
- 적용 제외는 법정 사유와 존속 시작·종료일을 입력받는다. 단순 자금난이나 소송 제기 사실만으로 제외를 확정하지 않는다. 제외 사유의 법적 자격이 확인되지 않으면 그 영향을 받는 금액을 보류한다.
- 지급한 날까지 이전 잔액에 이자가 붙고 다음 날부터 원금 변제분을 차감한다. 부분 입금의 원금 충당액이 불명확하면 민법 제479조의 비용·이자·원본 순서를 임의로 생략하지 않는다. 이번 계산은 채권별 원금 충당액이 확인된 자료를 받는다.
- 계산일은 명시된 날짜를 우선하며 생략만 조회 기준일로 대체한다. 잘못된 날짜·숫자, 역전 기간, 초과 변제, 중복 채권 ID는 보류한다.
- 판결·약정 이율, 소송촉진법, DC 부담금 지연이자는 별도 근거이므로 일반 임금 20% 계산으로 대체하지 않는다.

## 입력과 결과

기존 `arrear_amount`, `arrear_due_date`, `arrear_calc_date`를 유지한다. 신규 입력은 채권 종류, 퇴직 효력일/마지막 재직일, `debtor_is_merchant: bool | None`, 채권 목록, 채권별 확정 원금 변제, 법정 제외 기간이다. 분석 스키마·정규화·WageInput·facade·답변까지 같은 의미로 전달한다. 입사·퇴직 입력 `end_date`를 의미 확인 없이 이자 기산일로 바꾸지 않는다.

내역은 채권 ID, 구간 시작·종료(포함), 잔액, 적용 이율, 근거 규칙, 일수, 이자를 남긴다. 합계는 채권별 미반올림 이자를 합산한 뒤 기존 원 단위 반올림 규약으로 표시한다. 남은 원금·누적 이자·기지급 이자·남은 이자·합계가 대조되어야 한다. 부분 지급의 `interest_amount`는 확인된 이자 충당액이며 이자 지급이 없다고 확인했으면 0이다. 미확인이면 누적 이자와 원금은 산정하되 남은 이자와 청구 합계를 보류한다. 다른 채권의 발생 이자로 초과 충당을 상쇄하지 않는다. 이자는 단리이며 365일 분모를 사용한다.

소멸시효 안내는 임금의 정기지급일과 퇴직급여의 권리 행사 가능일을 구분한다. 윤년 2월 29일에서 3년 뒤 대응일이 없는 경우 월말을 사용한다. 중단·정지·승인·재판상 청구 등의 사실을 모르므로 권리 소멸을 확정하지 않는다.

## 퇴직 날짜 세부 계약

퇴직 효력이 오전 0시에 발생하면 민법 제157조 단서에 따라 초일을 산입한다. 경기도교육청의 공식 사례는 2024-05-31까지 재직하고 06-01 퇴직하면 06-14까지 지급으로 안내한다. 따라서 `arrear_last_employed_date`의 다음 날 또는 명시된 `arrear_retirement_effective_date`를 같은 효력일로 정규화하고, 둘 다 있으면 일치해야 한다. 기본 말일은 효력일+13일이다. 퇴직 일중에 발생하는 별도 지급사유는 이 계약으로 추정하지 않는다.

토·일요일 및 명시된 `arrear_deadline_holidays` 목록에 해당하는 기간 말일은 다음 날로 넘긴다. 공휴일 목록이 없으면 공휴일 조정을 확인하지 않은 조건부 추정임을 표시한다. 정기지급일은 이미 확정된 계약 지급기일 입력이며 이 기간 계산으로 변경하지 않는다.

원금 변제 입력은 `date`, `principal_amount`, `allocation_confirmed=true`를 요구한다. 남은 이자·청구 합계 확정에는 각 지급의 `interest_amount`도 필요하다. 이는 지급 총액을 임의로 원금에 우선 충당하는 기능이 아니다. 제외 구간은 `start_date`, `end_date`, 법정 `reason`, `eligible=true`를 받는다.

## 검증

300만 원·2026-01-01 지급기일·01-31 계산 → 30일·49,315원. 2025-10-22와 10-21 지급기일 경계, 퇴직 전후 기산 유지, 퇴직 14일 경계, 상인 여부 미확인 5%/6%, 부분 원금 변제, 복수 채권, 제외 기간, 윤년·잘못된 날짜·지연 0일을 회귀로 고정한다. 공개 HTML 두 사본과 실제 채팅 답변을 함께 검증한다. 기존 CLI 체불 사례의 boolean 입력은 명시된 날짜 입력으로 갱신한다.

## 리뷰 반영

독립 리뷰의 기지급 이자 중복, 비근로자 연20% 적용, 신규 채권 입력 자동 감지 누락을 재현 후 수정했다. 프리랜서·노무제공자 입력은 근로기준법상 근로자 여부를 확인하도록 보류하며, 직접 facade 호출도 같은 보호를 적용한다. 채권 목록·퇴직급여 날짜 입력 및 잘못된 명시 입력은 자동 감지에서 누락하지 않는다.
