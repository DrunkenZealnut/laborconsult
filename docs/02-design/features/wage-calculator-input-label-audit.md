## 범위와 판단

`analysis_qna_all.jsonl`의 계산 필요 행 중 기준 버전 `resolve_calc_type_strict`로 해석되지 않은 **106행·43라벨**, 그중 **기타 62행**의 질문 요약을 전부 읽고 분류했다. 계산 필요 표시는 지급 의무·절차 상담도 포함하므로 106개 신규 계산 수요로 해석하지 않는다. `기타`에 포괄 기본 계산기를 배정하지 않는다.
