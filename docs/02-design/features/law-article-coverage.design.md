### 3.2 2단 선택 (D1)

```python
@dataclass(frozen=True)
class KeywordLaw:
    name: str
    refs: tuple[str, ...]          # 주 조문
    match: Callable[[str], bool]
    extra: tuple[str, ...] = ()    # 보충 조문 — 주 조문이 남긴 자리에만

def keyword_laws(query, limit=KEYWORD_LAW_LIMIT):
    fired = [r for r in KEYWORD_LAWS if r.match(q)]
    out = select_law_refs([x for r in fired for x in r.refs], limit=limit)
    if len(out) < limit:
        out += select_law_refs([x for r in fired for x in r.extra],
                               exclude_keys={law_ref_key(x) for x in out}, limit=limit - len(out))
    return out
```

- `warm_law_names()`와 R9·AC3은 `refs`와 `extra`를 **모두** 본다.
- 기존 R9·R10 단언은 2단 선택 뒤에도 그대로 성립한다(검증 확인).

### 3.5 삭제 조문 3중 차단 (D5)

**① 조회 시점 — `legal_api.fetch_relevant_articles._fetch_one`**
- `fetch_article`이 돌려준 텍스트가 **삭제 조문**이면 싣지 않는다. 삭제 조문의 판정: 조문 머리 줄(첫 줄은 조문번호, 둘째 줄부터 본문 — `_extract_article` 형식)에서 `re.M`으로 `^제\d+조(의\d+)?\s*삭제\b` 일치, 그리고 그 밖에 항 본문이 없는 경우.

**감지**

**문장** (고시·조문 원문의 요약 — 사실마다 앵커가 있다)
1. 뇌혈관·심장 질병의 업무관련성은 고용노동부고시 제2026-14호로 판단한다. 만성 과로 기준은 다음과 같다.
   - 발병 전 12주 동안 1주 평균 60시간(발병 전 4주 동안 1주 평균 64시간)을 초과하면 관련성이 강하다.
   - 52시간을 초과하면 길어질수록 관련성이 증가한다. 업무부담 가중요인이 있으면 관련성이 강하다. 가중요인은 근무일정 예측이 어려운 업무, 교대제, 휴일 부족, 유해 작업환경(한랭·온도변화·소음), 육체적 강도, 시차가 큰 잦은 출장, 정신적 긴장이다.
   - 52시간을 넘지 않아도 가중요인에 복합적으로 노출되면 관련성이 증가한다.
2. 오후 10시부터 다음 날 6시까지의 야간근무는 주간근무의 30%를 가산(휴게시간 제외)해 업무시간을 산출한다. 근로기준법 제63조 제3호의 감시·단속적 근로로 승인받은 경우와 이와 유사한 업무는 제외한다.
3. 단기 과로: 발병 전 1주일 이내 업무의 양이나 시간이 이전 12주(발병 전 1주일 제외)의 1주 평균보다 30퍼센트 이상 늘었거나, 업무 강도·책임·환경이 적응하기 어려운 정도로 바뀐 경우다.
4. 급성: 증상 발생 전 24시간 이내에 업무와 관련된 돌발적이고 예측 곤란한 사건의 발생과 급격한 업무 환경의 변화가 있고, 그로 인해 뇌혈관·심장혈관의 병변 등이 자연경과를 넘어 급격하고 뚜렷하게 악화된 경우다.
5. 보험급여를 받을 권리는 3년간 행사하지 않으면 시효로 소멸한다. 장해급여·유족급여·장례비·진폐보상연금·진폐유족연금은 5년이다(산업재해보상보험법 제112조 제1항). 오래된 사건이면 시효부터 확인하고, 발병 전 4주·12주 근무표와 출퇴근 기록을 확보하도록 안내한다.

### 13.2 구현 세부

- **파견 구어:** `(?<!중)지시`. "원청이 하청 작업을 중지시켰다"의 '지시'가 걸렸다.
- **경영상 해고 동사:** "(그만) 나오지 말라"는 넣지 않는다. 휴업 지시와 같은 표현이라 제46조와 갈리지 않는다.
- **휴업수당 결과:** `ShutdownAllowanceResult.is_applicable`을 둔다. 요약은 "미적용 (상시 4명 이하 사업장)"으로만 쓴다. 이전에는 "0원 / 적용 기준: 평균임금 70%"가 함께 찍혀 제46조가 적용되는 것처럼 읽혔다.
- **업로더:** `collect_docs()`로 분리해 테스트할 수 있게 했다. 실측 결과, 적재 대상 14건(= 원장)과 앵커 전용 25건을 건너뛴다.
- **`check_law_freshness`:**
  - `_anchor_warnings`를 `_anchor_checks`로 바꿨다(실패와 경고를 함께 반환).
  - `_annex_absence`를 지우고 `annex_listing`·`annex_claim_holds`·`annex_text`로 대체했다.
  - `_liveness_checks`를 넣었다.
  - `check_law`는 루트를 돌려준다.
  - 고시 개정 감지는 발령번호가 아니라 저장본 `date`와 현행 시행일 대조로 한다. 오래된 고시는 게시판 목록에서 발령번호를 얻지 못하기 때문이다.
- **`fetch_official_rules --check-updates`:** `ADMRUL_LAW_GO_KR_ONLY` 문서는 건너뛰고 안내만 남긴다. 게시판 최근 100건에 오래된 고시가 없으면 매번 '조회 실패'로 찍힌다.
- **별표 주장:** 20개(장 단위 1 + 조·항 단위 19)다. 실제 별표(현행판)와 fixture에서 모두 참이다.
- **fixture:** `data/annex_fixtures/lsa_enf_annex1_20251023.txt`·`fta_enf_annex1_20210408.txt`(첫 줄은 출처 주석)다.
- **테스트:** AC1~AC16을 18개 메서드로 구현했다.
